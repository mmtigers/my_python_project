# 仕様書 (docs/specifications/) 索引

このディレクトリには、リポジトリの3サブシステム(`MY_HOME_SYSTEM`・`family-quest`・`DDD`)を構成する各ソースファイルを、ソースコードのみを根拠に単体でリバースエンジニアリング解析した仕様書(Markdown)が格納されています。

## 構成

| ディレクトリ / ファイル | 内容 |
| --- | --- |
| [全体設計書.md](./全体設計書.md) | 3サブシステムの役割・データフロー・システム間連携をまとめた全体アーキテクチャ概要。個別ソースファイルには対応しない例外ドキュメント。 |
| [ラズパイデプロイ前動作検証手順.md](./ラズパイデプロイ前動作検証手順.md) | Raspberry Piへのデプロイ前に行う動作検証の運用手順書。 |
| [MY_HOME_SYSTEM/](./MY_HOME_SYSTEM/README.md) | IoT制御・環境監視・API統合ルーティングを担うFastAPIバックエンド(69件)。 |
| [family-quest/](./family-quest/README.md) | クエスト管理をRPG風UIで提供するReact/TypeScriptフロントエンド(42件、`src/`構造をミラー)。 |
| [DDD/](./DDD/README.md) | 動画・画像等のデータ自動収集バッチ処理群(3件)。 |

## 仕様書の規約

- ソースファイル1つにつきMarkdown仕様書1つが対応します(例外: 本ファイルおよび各ディレクトリの`README.md`、`全体設計書.md`)。
- 各仕様書は「解析メタ情報」「ファイルの概要」「外部依存関係」「主要要素の定義」「処理フロー図」「依存関係図」「次のステップ」「保守上の注意点」「不明事項一覧」「自己検証結果」の10セクションで構成される固定フォーマットです。
- 単体解析の限界を補うため、各仕様書には「関連ドキュメント」(関連する他仕様書へのリンク)と、不明事項が他ドキュメントの解析結果から判明した場合の「相互参照による補足情報」を追加しています(詳細は[全体設計書.md 6-5](./全体設計書.md)参照)。
- ソースと仕様書の対応関係は `.github/scripts/check_spec_drift.py` によって自動監査されています(PR差分チェック・週次全体監査)。
